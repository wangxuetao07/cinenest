## 0. 项目概述

**中文名**：影巢  
**英文名**：CineNest  
**Slogan**：把你的硬盘变成私人影院。

**核心功能**：
1. 用户可添加任意本地目录作为“媒体库”。
2. 系统定期扫描目录中的视频文件，提取元数据，生成缩略图。
3. 网页端以类似主流视频网站的方式展示视频。
4. 点击视频可在浏览器内直接播放，支持进度记忆、继续观看。
5. 支持搜索、收藏、播放列表、扫描日志、设置。

**非目标（v1 不做）**：
- 多用户权限体系（v1 仅单用户，可选密码）
- TMDB 刮削（v2 再做）
- 弹幕、评论、分享

## 4. 数据库设计

SQLite 单文件，启用 WAL 与 foreign_keys。表结构与字段如下，字段名不可变更。

### 4.1 建表 SQL

写入 `server/db/schema.sql`：

```sql
PRAGMA journal_mode = WAL;
PRAGMA foreign_keys = ON;

CREATE TABLE IF NOT EXISTS library (
  id          INTEGER PRIMARY KEY AUTOINCREMENT,
  name        TEXT NOT NULL,
  path        TEXT NOT NULL UNIQUE,
  scan_cron   TEXT DEFAULT '0 3 * * *',
  enabled     INTEGER DEFAULT 1,
  created_at  TEXT DEFAULT (datetime('now','localtime'))
);

CREATE TABLE IF NOT EXISTS video (
  id            INTEGER PRIMARY KEY AUTOINCREMENT,
  library_id    INTEGER NOT NULL REFERENCES library(id) ON DELETE CASCADE,
  file_path     TEXT NOT NULL UNIQUE,
  file_name     TEXT NOT NULL,
  title         TEXT,
  ext           TEXT,
  size          INTEGER,
  mtime         INTEGER,
  duration      REAL,
  width         INTEGER,
  height        INTEGER,
  video_codec   TEXT,
  audio_codec   TEXT,
  bitrate       INTEGER,
  thumb_path    TEXT,
  poster_path   TEXT,
  favorite      INTEGER DEFAULT 0,
  play_progress REAL DEFAULT 0,
  play_duration REAL DEFAULT 0,
  last_played   TEXT,
  added_at      TEXT DEFAULT (datetime('now','localtime')),
  updated_at    TEXT DEFAULT (datetime('now','localtime'))
);

CREATE INDEX IF NOT EXISTS idx_video_library ON video(library_id);
CREATE INDEX IF NOT EXISTS idx_video_added   ON video(added_at DESC);
CREATE INDEX IF NOT EXISTS idx_video_title   ON video(title);

CREATE TABLE IF NOT EXISTS tag (
  id   INTEGER PRIMARY KEY AUTOINCREMENT,
  name TEXT NOT NULL UNIQUE
);

CREATE TABLE IF NOT EXISTS video_tag (
  video_id INTEGER NOT NULL REFERENCES video(id) ON DELETE CASCADE,
  tag_id   INTEGER NOT NULL REFERENCES tag(id)   ON DELETE CASCADE,
  PRIMARY KEY (video_id, tag_id)
);

CREATE TABLE IF NOT EXISTS playlist (
  id         INTEGER PRIMARY KEY AUTOINCREMENT,
  name       TEXT NOT NULL,
  created_at TEXT DEFAULT (datetime('now','localtime'))
);

CREATE TABLE IF NOT EXISTS playlist_item (
  id          INTEGER PRIMARY KEY AUTOINCREMENT,
  playlist_id INTEGER NOT NULL REFERENCES playlist(id) ON DELETE CASCADE,
  video_id    INTEGER NOT NULL REFERENCES video(id)    ON DELETE CASCADE,
  sort        INTEGER DEFAULT 0
);

CREATE TABLE IF NOT EXISTS scan_log (
  id          INTEGER PRIMARY KEY AUTOINCREMENT,
  library_id  INTEGER REFERENCES library(id) ON DELETE CASCADE,
  started_at  TEXT,
  finished_at TEXT,
  added       INTEGER DEFAULT 0,
  updated     INTEGER DEFAULT 0,
  deleted     INTEGER DEFAULT 0,
  failed      INTEGER DEFAULT 0,
  message     TEXT
);

CREATE TABLE IF NOT EXISTS setting (
  key   TEXT PRIMARY KEY,
  value TEXT
);
```

### 4.2 启动迁移

`server/db/migrate.js` 在服务启动时执行一次 `schema.sql`，幂等。

## 5. API 契约

统一前缀 `/api`。所有响应为 JSON，错误格式：

```json
{ "error": "错误描述" }
```

状态码：200 成功，400 参数错误，404 不存在，500 内部错误。

### 5.1 媒体库

| 方法 | 路径 | 请求 | 响应 |
|---|---|---|---|
| GET | `/api/libraries` | - | `[{id,name,path,scan_cron,enabled,created_at}]` |
| POST | `/api/libraries` | `{name, path, scanCron?}` | `{id}` |
| PATCH | `/api/libraries/:id` | `{name?, scanCron?, enabled?}` | `{ok:true}` |
| DELETE | `/api/libraries/:id` | - | `{ok:true}` |
| POST | `/api/libraries/:id/scan` | - | `{total,added,updated,deleted,failed}` |

约束：
- `path` 必须为绝对路径，且目录存在，否则返回 400。
- `path` 唯一，重复返回 400。

### 5.2 视频

| 方法 | 路径 | 请求 | 响应 |
|---|---|---|---|
| GET | `/api/videos` | `?libraryId&q&sort&page=1&size=40&favorite` | `{total,page,size,items:[Video]}` |
| GET | `/api/videos/:id` | - | `Video` |
| PATCH | `/api/videos/:id` | `{title?, favorite?, tags?}` | `{ok:true}` |
| DELETE | `/api/videos/:id` | - | `{ok:true}`（仅删记录） |
| GET | `/api/videos/recent` | `?limit=20` | `[Video]` |
| GET | `/api/videos/continue` | `?limit=20` | `[Video]`（play_progress>0 且未看完） |

`sort` 允许值：`added_at DESC`（默认）、`added_at ASC`、`title ASC`、`duration DESC`、`size DESC`。

`Video` 对象字段与 `video` 表一致，`thumb_path`、`poster_path` 返回时统一转为 API 路径：

- 缩略图：`/api/thumb/:id`
- 海报：`/api/poster/:id`

### 5.3 播放与流媒体

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/stream/:id` | 支持 HTTP Range，直出 |
| GET | `/api/thumb/:id` | 返回缩略图 jpg |
| GET | `/api/poster/:id` | 返回海报 jpg，无则回退 thumb |
| GET | `/api/subtitle/:id` | 查找同名字幕，转 vtt 返回 |
| GET | `/api/stream/:id/hls.m3u8` | v2 实现，v1 可返回 501 |
| GET | `/api/stream/:id/hls/:seg.ts` | v2 实现 |

**Range 响应必须满足**：

- 无 `Range` 头：200，`Content-Length`、`Content-Type`、`Accept-Ranges: bytes`。
- 有 `Range`：206，`Content-Range: bytes start-end/total`。
- 越界：416。

**MIME 映射**：

```text
.mp4/.m4v → video/mp4
.webm     → video/webm
.mkv      → video/x-matroska
.mov      → video/quicktime
.avi      → video/x-msvideo
.ts       → video/mp2t
.flv      → video/x-flv
其他      → application/octet-stream
```

### 5.4 历史与进度

| 方法 | 路径 | 请求 | 响应 |
|---|---|---|---|
| POST | `/api/history/:id` | `{progress:number, duration:number}` | `{ok:true}` |
| GET | `/api/history` | `?limit=50` | `[Video]` |
| DELETE | `/api/history/:id` | - | `{ok:true}`（清空该视频进度） |

`POST` 同时更新 `last_played = datetime('now','localtime')`。

### 5.5 收藏

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/favorites` | 收藏列表，参数同 `/api/videos` |

### 5.6 播放列表

| 方法 | 路径 | 请求 |
|---|---|---|
| GET | `/api/playlists` | - |
| POST | `/api/playlists` | `{name}` |
| DELETE | `/api/playlists/:id` | - |
| GET | `/api/playlists/:id/items` | - |
| POST | `/api/playlists/:id/items` | `{videoId}` |
| DELETE | `/api/playlists/:id/items/:videoId` | - |

### 5.7 搜索

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/search?q=` | 匹配 `title`、`file_name`，返回 `{items:[Video]}` |

### 5.8 任务与日志

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/tasks` | 返回最近 50 条 `scan_log` |
| GET | `/api/tasks/running` | 当前是否有扫描在进行 |

### 5.9 设置

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/settings` | 返回 `{key:value}` |

## 7. 关键实现细节

### 7.1 扫描器 `scanner.js`

流程：

```text
1. 读取 library。
2. fast-glob 遍历，pattern = path.posix.join(lib.path.replace(/\\/g,'/'), '**/*')。
3. ignore：@eaDir、$RECYCLE.BIN、System Volume Information、.git。
4. 过滤 videoExt。
5. 对每个文件：
   a. fs.statSync 拿 size、mtimeMs。
   b. 查库：若 size 与 mtime 都未变，跳过。
   c. ffprobe 拿元数据。
   d. makeThumb 拿缩略图。
   e. 有记录 → update；无记录 → insert。
6. 清理：库中该 library 的所有记录，若文件不存在则删除记录。
7. 写 scan_log。
8. 返回统计。
```

并发：使用 `p-limit(3)` 控制 ffprobe 并发。

错误：单个文件失败不中断，计数 failed，继续。

### 7.2 ffprobe 封装 `probe.js`

- 用 `spawn`，参数数组，禁止字符串拼接。
- `windowsHide: true`。
- 返回：`{duration, bitrate, width, height, videoCodec, audioCodec}`。
- 失败时 reject，由调用方捕获。

### 7.3 缩略图 `thumbnail.js`

- 文件名：`md5(file_path) + '.jpg'`。
- 已存在则直接返回。
- ffmpeg 参数：

```text
-ss <max(1, min(duration*0.1, 30))>
-i <file>
-frames:v 1
-vf scale=480:-1
-q:v 4
-y <out>
```

- 失败返回 null，不抛异常。

### 7.4 流媒体 `stream.js`

- 按第 5.3 节实现。
- 使用 `fs.createReadStream(path, {start, end})`。
- 文件不存在返回 404，不抛异常。

### 7.5 字幕 `subtitle.js`

- 在视频同目录查找同名 `.srt` / `.ass` / `.vtt`。
- srt/ass 用 ffmpeg 转 vtt：

```text
ffmpeg -i input.srt -f webvtt output.vtt
```

- 返回 `Content-Type: text/vtt; charset=utf-8`。
- 找不到返回 404。

### 7.6 监听 `watcher.js`

- 对每个启用的 library 启动 chokidar。
- `ignoreInitial: true`，`awaitWriteFinish: { stabilityThreshold: 5000 }`。
- 事件触发后 3 秒防抖，再调用 `scanLibrary`。

### 7.7 定时 `scheduler.js`

- 读取每个 library 的 `scan_cron`，用 node-cron 注册。
- 时区 `Asia/Shanghai`。
- 启动时立即注册所有启用库。

### 7.8 错误中间件

- 捕获所有未处理异常，返回 `{error: message}`，状态 500。
- 记录到 `data/error.log`。

## 10. 注意事项

### 10.1 Windows 路径

- 数据库存绝对路径，保留反斜杠（`D:\Movies\a.mp4`）。
- fast-glob 需要把 `\` 换成 `/`。
- spawn 传参用数组，禁止拼字符串。
- 判断文件存在用 `fs.existsSync`。

### 10.2 中文

- 所有文件读写默认 UTF-8。
- HTTP 响应头带 `charset=utf-8`。
- 前端字体优先中文字体。

### 10.3 性能

- SQLite 开 WAL。
- ffprobe 并发 ≤ 3。
- 缩略图缓存命中直接返回。
- 列表接口默认分页 40。

### 10.4 安全（本地场景）

- 默认仅本机与局域网可访问。
- v1 不做登录，若需可加 `setting` 表中 `auth.enabled` 与 `auth.password`。
- 所有文件操作限制在已注册的 library 路径内，禁止路径穿越。

### 10.5 日志

- 启动日志、扫描日志、错误日志分开。
- 错误日志写 `data/error.log`，单文件超 10MB 轮转。

### 10.6 依赖版本

- 所有依赖锁定 `package-lock.json`。
- `better-sqlite3` 需要与本机 Node 版本匹配的预编译包；若安装失败，提示用户安装 Visual Studio Build Tools。
